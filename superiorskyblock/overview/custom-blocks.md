# Custom Blocks

The plugin supports multiple plugins that add custom blocks to the game.

You can use the custom blocks anywhere across the plugin:

* Generators
* Block Worth or Levels
* Block Counts
* Missions
* etc.

## ItemsAdder

[https://www.spigotmc.org/resources/73355/](https://www.spigotmc.org/resources/73355/)

You can use custom blocks from ItemsAdder by adding "ITEMS\_ADDER:" prefix, then the name of the custom block from the plugin.

## Oraxen

[https://www.spigotmc.org/resources/72448/](https://www.spigotmc.org/resources/72448/)

You can use custom blocks from Oraxen by adding "ORAXEN:" prefix, then the name of the custom block from the plugin.
